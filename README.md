### 🚀 Featured project

**[CertWatch](https://github.com/Mari-li/certwatch)** — a self-hosted SSL/TLS certificate expiry monitor.
Checks every domain daily and flags expiring, expired, mismatched or untrusted certificates before they take a site down.

- Framework-independent domain logic, fully unit-tested with real X.509 certificates
- Queued checks, REST API and a Vue 3 dashboard
- Dockerized (Nginx, PHP-FPM, queue worker, scheduler, MySQL), CI on GitHub Actions
